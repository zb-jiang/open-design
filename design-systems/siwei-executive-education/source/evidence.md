# 四为高管教育设计体系来源记录

本设计体系基于用户提供的本地 VI 和 PPT 模板资料整理。

## Source Assets

- `assets/logo.png`：四为 Logo。
- `assets/primary-color.png`：标准色，含四为红 `#E60012`、四为黑 `#080404`、白色 `#FFFFFF`。
- `assets/secondary-color.png`：辅助色，灯塔社蓝 `#436DB4`。
- `assets/chinese-font.png`：中文字体规范，思源黑体系列。
- `assets/english-font.png`：英文字体规范，Roboto 系列。
- `source/ppt/`：PPT SVG 模板和设计规范。

## Extracted Brand Constants

- 四为红：Pantone 185C，CMYK 0 100 100 0，RGB 230 0 18，HTML `#E60012`。
- 四为黑：Pantone Black C，CMYK 90 87 87 77，RGB 8 4 4，HTML `#080404`。
- 白色：RGB 255 255 255，HTML `#FFFFFF`。
- 灯塔社蓝：Pantone 7455C，CMYK 77 54 0 0，RGB 67 109 180，HTML `#436DB4`。

- 画布：16:9，1280 × 720。
- 安全边距：左右 60px，上 60px，下 40px。
- 基准网格：40px。
- 页面类型：封面页、目录页、章节页、内容页、结束页。
- 表达风格：高管汇报、战略咨询、数据驱动、结构化思维、专业留白。
