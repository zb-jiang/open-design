# 四为高管教育

> Category: Company Brand
> 基于四为高管教育 VI、字体、色彩和 PPT 模板沉淀的多场景品牌设计体系，适用于高管课程、战略咨询、商务汇报、数据报告、官网、营销页、后台、看板和海报。

## 1. Visual Theme & Atmosphere

四为高管教育的视觉气质应体现：专业、可信、结构化、思想密度、高级商务感。

核心关键词：

- 高管教育
- 战略咨询
- 结构化思维
- 商业洞察
- 组织成长
- 课程影响力
- 专业留白
- 结论先行

默认视觉倾向为 `战略咨询模式`：白底、大留白、强网格、少装饰、标题明确、内容以框架和数据支撑。

可根据用户提示切换场景模式：

1. **战略咨询模式**：适合董事会汇报、战略规划、组织变革、投资分析、商业计划。要求最克制，强调 MECE、数据、逻辑框架和结论先行。
2. **高管课程模式**：适合课程课件、培训讲义、知识框架、案例拆解。允许更清晰的模块化教学结构，强调“概念—案例—行动”。
3. **品牌传播模式**：适合官网、活动页、招生页、营销海报。允许更高比例使用四为红和 Logo，但仍要高级、现代、留白充分。
4. **数据报告模式**：适合研究报告、经营看板、指标分析。强调大数字、图表、矩阵、对比、趋势线和清晰结论。
5. **正式商务模式**：适合企业客户、政府客户、合作方案。稳重、低噪声、低装饰，强调可信、严谨和可执行。

如果用户没有指定模式，默认使用 **高管课程模式**。

## 2. Color

品牌标准色：

- **Primary / Brand Red:** `#E60012` — 四为红，主识别色，来自 Pantone 185C。必须作为默认主强调色、主按钮、品牌高亮、封面焦点、CTA、重要结论和风险/警示类强调。
- **Heading / Brand Black:** `#080404` — 四为黑，标题、主文本、高权重信息。用于建立稳定、专业、可信的气质。
- **Background / White:** `#FFFFFF` — 白色，主背景和留白基础。
- **Secondary / Beacon Blue:** `#436DB4` — 灯塔社蓝，辅助色，来自 Pantone 7455C。只能用于信息强调、图表辅助序列、咨询感装饰线、数据报告中的结构色；不要替代四为红成为主按钮或主品牌高亮。

辅助蓝阶：

- `#365A98` — 深蓝，用于深色标题条、图表深色序列。
- `#6C91CC` — 中浅蓝，用于辅助图表和图标。
- `#C8D4E8` — 浅蓝，用于背景块和弱强调。

中性色：

- `#F7F8FA` — 页面浅灰背景。
- `#F1F3F6` — 模块背景、页眉页脚。
- `#E5E7EB` — 细边框、分隔线。
- `#4B5563` — 正文灰。
- `#7A808A` — 注释、来源、页脚。

使用规则：

- 四为红是品牌识别色，但不要在内容页大面积滥用；默认只用于关键焦点。
- 四为黑用于标题和主信息，保证高对比和稳定气质。
- 灯塔社蓝用于咨询、数据、信息类场景，可作为 PPT 顶部线、章节色、图表主色。
- 页面背景优先白色或极浅灰，保持专业留白。
- 同一页面内高饱和色不超过 2 个。
- 图表色优先顺序：`#436DB4`、`#E60012`、`#6C91CC`、`#365A98`、`#D97706`、`#1F8A5B`。
- 所有颜色必须使用纯色，不使用渐变、叠色、高光过渡、霓虹光影、发光效果。

## 3. Typography

中文字体：

- **主字体：** 思源黑体系列。
- 推荐字重：Heavy / Bold / Medium / Regular / Light。
- 标题优先使用 Heavy 或 Bold。
- 正文优先使用 Regular 或 Medium。

英文字体：

- **主字体：** Roboto。
- 推荐字重：Black / Bold / Medium / Regular / Light。
- 英文标题可用 Roboto Black / Bold。
- 英文正文用 Roboto Regular。

字体 fallback：

- 中文：`"思源黑体", "Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif`
- 英文：`"Roboto", "Inter", "Segoe UI", Arial, sans-serif`

PPT 字号层级：

- 封面主标题：52–64px，Bold / Heavy。
- 章节页标题：44–52px，Bold / Heavy。
- 内容页标题：28–36px，Bold。
- 卡片标题：18–24px，Bold / Medium。
- 正文：14–18px，Regular。
- 注释/来源：11–13px，Regular。
- 大数字：44–72px，Bold / Heavy。

Web 字号层级：

- Hero H1：56–76px。
- Section H2：36–48px。
- Card H3：20–28px。
- Body：15–17px。
- Caption：12–13px。

排版原则：

- 标题必须像“观点句”，不要只写抽象名词。
- 中文标题允许短句化、结论化，例如“组织能力决定增长上限”。
- 避免艺术字、手写体、卡通字体和过度字距。
- 中英文混排时，中文用思源黑体，英文用 Roboto，保持现代商业感。

## 4. Spacing & Grid

PPT 画布：

- 16:9 横版。
- 标准尺寸：1280 × 720。
- viewBox：`0 0 1280 720`。
- 页面安全边距：左右 60px，上 60px，下 40px。
- 基准网格：40px。

PPT 区域规则：

- 顶部品牌线：高度 5–6px，可用四为红或灯塔社蓝。
- 标题区：y=40–110。
- 内容区：y=130–620。
- 页脚区：y=640–720。
- 内容覆盖率建议小于 65%，保留高端商务留白。

Web 网格：

- 最大内容宽度：1180–1280px。
- Section 上下间距：80–120px。
- 卡片间距：20–32px。
- 卡片内边距：24–36px。
- Hero 区高度：首屏 680–860px。

布局节奏：

- 先建立明确网格，再放内容。
- 多模块页面使用 2 栏、3 栏、2×2 矩阵、左文右图、上结论下证据等稳定结构。
- 每页 PPT 只表达一个核心观点。
- 内容页避免密集堆叠；超过 5 个要点时转成分组、矩阵或流程图。

## 5. Layout & Composition

PPT 基础页面类型：

1. **封面页**
   - 白底或深色底。
   - 左侧或顶部品牌强调线。
   - Logo 不宜过大，放在角落或信息区。
   - 主标题大而克制，副标题解释主题。
   - 可使用低透明几何装饰，但不喧宾夺主。
   - 背景和装饰均使用纯色色块或细线，不使用渐变。
2. **目录页**
   - 使用 2×2 或 2×3 章节卡片。
   - 章节编号清晰，标题短句化。
   - 可用四为红标记当前重点章节，蓝色作为辅助章节色。
3. **章节页**
   - 允许使用大面积四为黑、深蓝或四为红，但只用于章节过渡。
   - 中央大标题 + 章节编号 + 简短说明。
   - 装饰极简，可使用细线、低透明网格、Logo 水印。
4. **内容页**
   - 顶部标题 + 核心观点条 + 主内容区 + 页脚来源。
   - 内容区可采用左右分栏、2×2 矩阵、数据卡片、流程图、时间轴、对比表。
   - 优先图形化表达，少用长段落。
5. **结束页**
   - 居中感谢语或行动号召。
   - 联系方式清晰。
   - Logo 和版权信息保持克制。

Web 页面类型：

- **官网 Hero**：大标题、可信副标题、CTA、品牌 Logo 或抽象几何图形。
- **课程介绍页**：课程收益、适合人群、模块大纲、导师介绍、报名 CTA。
- **后台/看板**：指标卡、趋势图、组织诊断雷达图、学员画像、课程完成率。
- **营销页/海报**：品牌红可以更强，但保持高级商务感，避免促销感过重。
- **研究报告页**：标题结论、大数字、图表、方法说明、来源注释。

组合原则：

- 结论先行：页面顶部优先出现结论，而不是背景介绍。
- 证据支撑：数据、案例、框架放在结论下面。
- 层次明确：标题、解释、证据、行动项必须有明显权重差异。
- Logo 露出克制：不要每个模块重复放大 Logo。

Logo 使用规则：

- 四为 Logo 来源：`assets/logo.png`。
- PPT、海报、官网 Hero、课程封面、营销页、封底页应尽量出现四为 Logo。
- PPT 封面建议放在左上角、右上角或项目信息区；内容页可放在页脚或页眉角落，保持小尺寸。
- 海报和营销页可以适度放大 Logo，但不能压过主题标题。
- 后台、数据看板、课程内页可弱化 Logo，只在导航、页眉或页脚保留品牌识别。
- 不要拉伸、变形、旋转、加投影、加描边或随意换色。
- 如果生成物无法直接读取图片文件，必须至少保留“红色印章形态 + 四为文字”的品牌识别位，并在代码中用注释标明应替换为 `assets/logo.png`。

## 6. Components

按钮：

- 主按钮：四为红 `#E60012`，白字，圆角 8–12px。
- 次按钮：白底黑字或浅灰底，边框 `#E5E7EB`。
- 商务/报告场景中按钮不要过度圆润，不要卡通化。
- 按钮必须使用纯色填充，不要渐变背景。

卡片：

- 白底或极浅灰底。
- 圆角 8–16px。
- 边框优先于重阴影。
- 可用 4–6px 左侧色条标记类别。

PPT 组件：

- 核心观点条：浅底 + 左侧红/蓝竖条 + 结论句。
- 数据卡片：大数字 + 单位 + 解释 + 趋势标记。
- 三段式观点卡：问题 / 洞察 / 行动。
- 2×2 矩阵：适合能力模型、优先级、组织诊断。
- 时间线：适合课程路径、项目计划、发展阶段。
- 对比表：适合现状 vs 目标、传统模式 vs 四为方案。
- 框架图：适合战略、组织、人才、领导力模型。

图表：

- 主要序列用灯塔社蓝。
- 关键点用四为红。
- 正向数据可用稳重绿色，警示可用红色或琥珀色。
- 每个图表必须有结论标题，不要只有图形。
- 坐标、图例、来源要克制但可读。

图形语言：

- 使用线性几何、矩形、细线、低透明色块、网格。
- 可使用 Logo 红色轮廓或抽象印章形态作为低透明背景元素。
- 避免卡通人物、二次元头像、夸张 3D、过度插画。

## 7. Motion & Interaction

Web 动效：

- 动效克制，150–250ms。
- Hover 可轻微上浮 2–4px 或增加浅阴影。
- 数据图表可使用渐入，但不要弹跳。
- 页面滚动动效应服务于层级呈现，不要炫技。

PPT 动效：

- 默认不设计复杂动画。
- 如果需要说明流程，可用分步出现、淡入、从左到右推进。
- 不使用旋转、弹跳、闪烁、爆炸、粒子等效果。

交互状态：

- Focus、hover、active、disabled 要清晰。
- 表单和后台界面要重视可读性和错误提示。
- 高管教育场景中，交互语言要成熟、直接、可信。

## 8. Voice & Brand

品牌语气：

- 专业、克制、可信。
- 有洞察，但不浮夸。
- 有教育属性，但不说教。
- 有咨询感，但不堆术语。

标题写法：

- 优先使用观点句。
- 示例：
  - “高管学习的核心不是知识输入，而是决策能力升级”
  - “组织增长进入新阶段，需要重构领导力系统”
  - “课程价值应落在业务结果和管理动作上”

正文写法：

- 短句、结构化、可执行。
- 少用空泛词，例如“赋能未来”“共创辉煌”。
- 多用业务词，例如“战略共识”“组织能力”“管理动作”“增长路径”“人才梯队”。

PPT 表达：

- 每页标题承担结论功能。
- 正文不超过 3–5 个要点。
- 数据页必须写清楚“所以什么”。
- 课程页要形成“认知框架 → 案例 → 行动清单”的学习闭环。

## 9. Anti-patterns

禁止或强烈避免：

- 卡通风、二次元风、潮玩风、手绘儿童插画。
- 任何形式的渐变背景、渐变按钮、渐变图表、霓虹光影、赛博朋克、低质科技蓝光效。
- 过度装饰、满屏元素、花哨背景。
- 随机使用非品牌色。
- 四为红在内容页大面积铺满导致压迫感。
- PPT 一页超过一个核心观点。
- 长段落堆满页面。
- 图表无结论、无来源、无解释。
- 使用艺术字、手写体、漫画字体。
- Logo 拉伸、变形、加投影、随意换色。
- 高管教育内容写成鸡汤口号或低质营销话术。

当用户要求“更活泼”“更年轻”时，也必须保持四为品牌边界：可以提高红色比例、增强节奏和图片使用，但不得变成卡通、二次元或花哨娱乐风。
