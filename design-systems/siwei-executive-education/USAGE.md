# 四为高管教育 Usage

面向 Open Design agents 的四为高管教育品牌设计体系使用说明。

## Read Order

1. 先读 `USAGE.md`，确认本次产物场景和风格模式。
2. 再读 `DESIGN.md`，遵守品牌色、字体、版式、表达语气和禁用项。
3. 生成 HTML / Web / Deck 时，优先复制 `tokens.css` 中的 CSS 变量。
4. 生成 PPT、海报、官网 Hero、课程封面、营销页时，应尽量使用四为 Logo：`assets/logo.png`。
5. 需要 PPT 页面结构时，参考 `source/ppt/` 下的 SVG 模板和 `source/ppt/design_spec.md`。
6. 需要 Logo、颜色或字体来源时，参考 `assets/` 下的 VI 图片。

## 场景模式

用户可以在提示词中显式指定以下模式：

- `战略咨询模式`：用于高管汇报、战略规划、组织变革、投资分析。克制、结构化、数据驱动，接近咨询公司风格。
- `高管课程模式`：用于课程课件、培训材料、知识框架。更清晰、更教学化，强调概念、案例、行动清单。
- `品牌传播模式`：用于官网、营销页、活动页、海报。允许更强的四为红和 Logo 露出，但仍保持高级、留白和秩序。
- `数据报告模式`：用于经营分析、看板、研究报告。以图表、指标、大数字、对比矩阵为主。
- `正式商务模式`：用于对外方案、政府/企业客户提案。稳重、低饱和、少装饰，强调可信和专业。

如果用户没有指定模式，默认使用 `高管课程模式`。

## Do

- 使用四为红 `#E60012` 作为品牌主识别色，但控制面积。
- 使用四为黑 `#080404` 做标题和高权重文本。
- 使用灯塔社蓝 `#436DB4` 作为辅助色、图表色、信息强调色。
- 中文优先使用思源黑体系列，英文优先使用 Roboto。
- PPT 默认 16:9，1280 × 720，安全边距 60px。
- 结构要清楚：结论先行、层级明确、每页只表达一个核心观点。
- PPT 页面优先使用封面、目录、章节、内容、结束五类基础模板。

## Avoid

- 不要卡通、二次元、潮玩、手绘插画风。
- 不要使用任何渐变，包括渐变背景、渐变按钮、渐变图表、霓虹、赛博朋克、强玻璃拟态。
- 不要把红色大面积铺满内容页，除非是封面或品牌传播场景。
- 不要使用花哨字体、艺术字、手写体。
- 不要一页 PPT 堆满文字；优先转成框架、图表、清单和结论。
- 不要随意引入非品牌色，图表辅助色也要保持克制。
